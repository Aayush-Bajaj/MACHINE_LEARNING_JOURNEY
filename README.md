# Machine Learning Journey

A practical, notebook-based record of my learning in **machine learning with Python**. This repository follows the workflow from data preparation and exploratory analysis to supervised learning, unsupervised learning, model selection, and applied prediction projects.

## Repository roadmap

| Section | Topics |
|---|---|
| [01 - Data Preprocessing](01_Data_Preprocessing/) | NumPy and Pandas foundations |
| [02 - Exploratory Data Analysis](02_Exploratory_Data_Analysis/) | Exploratory analysis with the insurance dataset |
| [03 - Supervised Learning](03_Supervised_Learning/) | Linear regression, logistic regression, K-nearest neighbors, decision trees, and ensemble learning |
| [04 - Unsupervised Learning](04_Unsupervised_Learning/) | K-Means clustering and PCA |
| [05 - Model Selection and Tuning](05_Model_Selection_and_Tuning/) | GridSearchCV and hyperparameter search |
| [06 - Projects](06_Projects/) | Heart disease prediction, insurance data analysis, and Titanic classification |

## Learning workflow

1. Prepare data and understand the features.
2. Perform exploratory data analysis before modelling.
3. Train supervised models and compare their behaviour.
4. Explore clustering and dimensionality reduction.
5. Apply model selection and hyperparameter tuning.
6. Evaluate project results in the context of the dataset and validation approach.

## Run the notebooks locally

```bash
git clone https://github.com/Aayush-Bajaj/MACHINE_LEARNING_JOURNEY.git
cd MACHINE_LEARNING_JOURNEY
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Open notebooks in Jupyter Notebook, JupyterLab, or Google Colab. Some notebooks refer to Colab paths or built-in Seaborn datasets; adjust paths or download the required dataset before running locally.
